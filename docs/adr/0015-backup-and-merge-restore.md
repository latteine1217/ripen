# 使用者備份以識別碼合併還原，CSV 只能匯出

使用者於 2026-11-01 確認：設定的「資料」區塊提供備份、從備份還原與匯出 CSV。還原採依識別碼合併，不提供取代模式；第一版不包含設定；CSV 只供試算表閱讀，不能匯回。

- 備份檔是現行資料庫的單檔 SQLite 快照，以資料庫備份機制產生，保留 `application_id` 與資料版本，不依賴 WAL，也不新增檔案格式版本。快照先在 App 暫存目錄建立並驗證可讀回，再一次寫到使用者選的位置，失敗不留下半成品。備份的語意只有完成的專注與分類；快照中的恢復狀態與完成日誌在還原時一律忽略。
- 還原先把選取的檔案複製到暫存目錄，原檔內容與修改時間不變。檔頭不是 Ripen 資料庫時拒絕為「不是備份」；資料版本高於 App 時拒絕並提示更新；較舊版本沿用 `schemaUpgrades` 在暫存副本上升級。完整性、讀取或數值範圍檢查失敗視為損壞。任何拒絕都不寫入目前資料。
- 紀錄與分類只新增識別碼不存在的項目；已存在者保留目前內容，不比較或覆寫欄位，延續 ADR-0007 與 ADR-0010 以識別碼為身分。名稱相同但識別碼不同的分類並存。新增紀錄引用的分類兩邊都不存在時以未分類寫入，不捏造分類。
- 資料庫不記錄刪除，因此本機刪除而備份中仍有的分類會被帶回；確認畫面列出將新增的分類名稱，使用者可之後再刪除（ADR-0012）。
- 確認前顯示將新增的專注數、分類與已存在而略過的專注數；沒有可新增項目時直接說明，不寫入也不要求確認。
- 寫入前以資料庫備份機制另存 `focus-log.pre-restore.sqlite`，只保留最近一份，新副本成功後才取代；安全副本失敗則停止還原。合併在單一交易內重新計算缺少的項目，失敗整批回滾；重試或重複還原不新增第二筆。
- 計時進行中可以還原，進行中的計時不受影響；有未保存的變更或載入錯誤時停用備份、還原與匯出。成功後重新讀取，統計、分類清單與成果卡立即更新。
- CSV 為 UTF-8 加 BOM、CRLF 換行與 RFC 4180 引號，一筆完成的專注一列並依開始時刻排序；欄名固定英文：`id`、`started_at_utc`、`started_at_local`、`duration_seconds`、`project_id`、`project_name`。以 `=`、`+`、`-`、`@`、Tab 或 CR 開頭的分類名稱加單引號，避免試算表執行公式。
- 設定不在備份中，搬到另一台 Mac 後需手動重設。升級前備份 `focus-log.pre-upgrade.sqlite` 與還原前安全副本只供復原，不構成日常備份。

## Considered Options

- 取代模式：以備份覆蓋目前資料，會遺失還原前新增的紀錄，也需要另一套確認與回復流程。
- 新增刪除紀錄資料表：可避免帶回已刪除的分類，但要改資料結構與版本，且要定義刪除在不同裝置間的先後；第一版以預覽列出分類名稱代替。
- CSV 可匯回：試算表編輯過的時間、時區與分類名稱難以安全對回識別碼，能匯回的格式只保留備份檔。
- 備份包含設定：設定多與裝置相關（快速鍵、外觀、選單列），搬機時是否沿用需要另外決定。
