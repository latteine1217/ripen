# 紅黃按鈕改變形態，介面永遠至少一個可見

番茄鐘的價值在於計時隨時看得到，因此除了以 ⌘Q 退出，主視窗、懸浮窗、瀏海島三者至少有一個在畫面上。為此偏離 macOS 慣例：黃色按鈕不縮到 Dock，而是把主視窗變成懸浮窗；紅色按鈕在沒有懸浮窗時把主視窗收成瀏海島，有懸浮窗時只隱藏主視窗。懸浮窗與瀏海島互斥；關閉懸浮窗而主視窗不在時，自動收成瀏海島。綠色按鈕不攔截：主視窗是固定尺寸，系統會讓它呈現停用的灰色，與其他固定尺寸的 macOS App 一致。

## Considered Options

- 沿用系統慣例（紅色關閉視窗、黃色縮到 Dock）：會出現「App 在跑但計時看不到」的狀態，與核心目的衝突。
- 讓懸浮窗與瀏海島同時存在：畫面上會有兩份相同的計時，狀態組合變多而沒有帶來新資訊。
- 隱藏綠色按鈕，或指派其他形態給它：只剩兩顆按鈕在 macOS 上少見；另指派形態則會多出第四種狀態，而現有三種已涵蓋需求。
