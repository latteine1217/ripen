# 配色依用途分角色，並以對比門檻自動檢查

使用者於 2026-10-30 確認：畫面依用途取色，不直接使用色值；每個角色在淺色與深色下都要達到對比門檻，由測試檢查，不靠逐張畫面目測。本決策取代 ADR-0008 中「階段色與超時色各有淺色背景適用的較深配色」的部分：每個強調色改為填色與內容色兩個角色。外觀選項與其餘規則不變。

- 底色與文字：Ripen 自己的介面（主視窗、懸浮窗）以 `AppPalette` 取色；系統畫出的介面（設定、sheet、popover、選單）與玻璃使用系統語意色，由系統負責。瀏海島固定深色（ADR-0004）。
- 強調色（階段色、超時色、分類代表色、品牌色）各有兩個角色：填色（`Phase.tint`、`ProjectColor.color`）用於圓點、圓環、長條與圖表；內容色（`contentTint`、`contentColor`、`Color.brandAccent`）用於文字與圖示。文字與圖形共用同一個環境 tint 時用內容色，它同時滿足填色門檻。
- 門檻：內容色至少 4.5:1，填色至少 3:1，在該深淺色下會出現的每種背景上都要成立。玻璃透出桌面，以最差情況為基準：深色玻璃視為灰度 0.30，淺色玻璃視為 0.85；另含實色表面、瀏海島的純黑與成果卡的紙張底色。
- 不合格時只調整亮度、不改色相，讓各色仍分得開。
- 各視窗最外層的 tint 是品牌內容色，漏設 tint 的元件不會露出系統強調色。

`RipenTests/ColorContrastTests.swift` 檢查以上所有組合；配色總覽另有逐格輸出（`appearance-*-palette`）供目測色相。

## Considered Options

- 每種外觀各一組強調色（黑、白、深色玻璃、淺色玻璃）：最貼近各背景，但色值數量加倍，且玻璃的實際底色仍隨桌面變化。
- 只保留一組強調色並整體提高亮度：圓點與圖表也會變淡，在淺色背景上失去份量。
