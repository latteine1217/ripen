# 成果卡以分類為單位

使用者於 2026-10-30 確認：一個分類只有一張成果卡，不再從每一筆完成紀錄各自開卡。本決策取代 ADR-0010 中「成果卡是所選專注與所屬分類目前累積的呈現」以及「從舊紀錄開啟時本次專注時間取自該筆紀錄」的部分；分類歸屬、最新統計與所有統計限同一分類的規則不變。

- 入口在分類詳細頁（含未分類）；分類還沒有完成的專注時沒有卡片。
- 卡片呈現分類累積時間、今日投入、完成次數、專注天數（有完成專注的日子數，依開始時刻歸日）與最近七天，不出現任何單筆紀錄的長度或日期。
- 每次開啟或重新整理都以最新紀錄重算；同一輪預覽與輸出共用同一份數據。
- 卡片納入的紀錄仍可復原或尚未寫入時可以預覽，但不能儲存、複製或分享；開卡後分類的紀錄有變動（復原或新的完成）時，須重新整理才能輸出，避免輸出已撤回或與預覽不一致的數字。

## Considered Options

- 保留「本次專注」格並改為最近一次專注：使用者選擇讓卡片完全不綁定單筆紀錄。
- 以平均每次專注長度取代「本次專注」：使用者選擇專注天數，強調持續投入而非單次長度。
- 卡片只計入已保存的紀錄以便隨時輸出：與統計頁在復原期內會差一筆，使用者選擇沿用「可預覽、暫停輸出」的契約。

## Consequences

完成摘要（#24）與懸浮窗、瀏海島的回饋（#25）若提供成果卡入口，開啟的是該次專注所屬分類的卡片。先前已輸出的圖片仍是靜態檔案，不受影響。
