# 倒數到 0 進入超時，按完成才結束

專注與休息倒數到 0 時不再自動結束，而是播放提醒後進入超時，計時以 `+xx:xx` 繼續往上數，直到使用者按「完成」才進入下一段；完成的專注記錄實際長度（設定長度加超時，扣掉暫停）。這讓統計反映真正專注了多久，而不是只記設定值。本決策取代 ADR-0002 中「倒數到 0 即結束」的部分；真實時間計時、提醒延到回來才播、依開始時刻歸日與 ⌘Q 取消的規則不變。

- 超時中「暫停／繼續」照常可用，「跳過」與「重設」由「完成」取代。
- 鎖定、睡眠或螢幕關閉的那一刻自動暫停，超時只算到那一刻，避免離開時累加不屬於專注的時間。
- 倒數到過 0 的專注就算完成的專注；超時中以 ⌘Q 退出時，以退出時刻的實際長度記錄。
- 「自動開始休息」改為按完成後自動開始下一段。
- 不提供「倒數到 0 就結束」的設定開關。

## Considered Options

- 只讓專注超時：統計只記專注，但使用者希望休息也能自行決定何時結束。
- 離開時照真實時間繼續累加（或設上限）：忘了按完成就會記下大量不屬於專注的時間。
- 保留舊行為作為設定選項：多一個設定與兩套規則，使用者選擇一律超時。
