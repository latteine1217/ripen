# 超時色的色相避開分類色

使用者於 2026-11-03 確認：專注超時與休息超時改用色環上與分類色、階段色都分得開的色相。本決策取代 ADR-0008 中「超時保留青綠與橘的語意」的部分；ADR-0013 的角色、對比門檻與「不合格時只調亮度」維持不變。

計時介面的顏色代表階段，分類色只出現在選單圓點與統計。舊的專注超時青綠（約 176°）與 Teal 分類幾乎同色，休息超時橘（約 32°）介於 Cocoa 與 Amber 之間；分類選了這些顏色時，超時圓環會被看成「這個分類的顏色」，青綠也容易被誤讀成已進入休息。

- 專注超時為洋紅：淺色 300°，深色 290°。深色偏紫，因為在深色玻璃上要達到 4.5:1 只能是高亮度的粉色，300° 以上會往 Rose 靠。
- 休息超時為芥末黃綠，約 68°，短休息與長休息共用。
- 色相差由 `ColorContrastTests` 檢查：淺色與深色、填色與內容色分別比對，專注超時與其他每個強調色至少差 30°，休息超時至少 25°。洋紅佔去 290–300° 後，色環上沒有能與所有強調色差到 30° 的位置，休息超時最寬只有約 28°（介於 Amber 與 Leaf），因此門檻放寬。
- 色值先依對比門檻取最接近背景的亮度，填色與內容色亮度相近，比照既有色票。

## Considered Options

- 超時沿用階段色，改以圓環形態（第二圈、脈動）表示：不再增加色相，但需要新的超時圓環設計，也失去「顏色一變就知道超時」的提示。
- 兩種超時共用 300°：不必放寬門檻，但專注超時與休息超時無法以顏色區分。
- 調整分類色讓出空間：會改變使用者已選定的分類顏色與統計圖。

已知但不在本決策範圍：長休息（約 215°）與 Ocean 分類色相相同。
