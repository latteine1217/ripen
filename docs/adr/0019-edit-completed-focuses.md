# 完成的專注與分類可以就地編輯，還原語意不變

使用者於 2026-11-09 確認：分類可以改名；完成的專注可以更正開始時刻與長度、重新歸類，或刪除單筆。入口在統計頁的分類詳細頁。

- 編輯只改內容，不改識別碼。分類改名後紀錄仍屬同一分類；重新歸類整筆改到另一個分類或未分類，不拆分時間（ADR-0010）。
- 只有已保存的紀錄可以編輯。還在復原期與尚未寫入（含寫入失敗待重試）的紀錄仍在完成日誌中，重試時又以內容比對已提交的紀錄，先停用並說明原因。等待恢復決定時一律停用。
- 更正以分鐘為單位，未改動的欄位保留原始精度。長度必須大於 0，結束時刻不得晚於現在；不檢查紀錄之間的重疊。
- 改名沿用新增分類的名稱規則：去掉前後空白後不得為空，也不得與其他分類同名（不分大小寫），否則停用送出並在名稱欄下方說明。改成自己原本的名稱（含只改大小寫）不算同名；規則之前已存在的同名分類維持不動，照常顯示與改名。還原備份仍以識別碼為身分，可能帶回同名分類（ADR-0015）。未分類不是分類，不能改名。
- 刪除單筆在編輯視窗內再確認一次，列出是哪一筆並說明不能復原，不提供復原膠囊：GLOSSARY 的復原只涵蓋跳過、重設與完成（同 ADR-0012）。
- 寫入失敗時與其他未保存的變更一樣保留重試，退出前提示，備份、還原與匯出停用；重新讀取歷史時先套用未保存的編輯，已刪除的紀錄不會因讀回舊資料而復活。
- 完成摘要維持完成那一刻的數字；成果卡依 ADR-0010 每次重算，已開著的預覽在涵蓋的紀錄內容改變時標示已變更。

## 資料格式

不升級資料版本。改名更新分類名稱，更正與重新歸類更新同一筆紀錄的開始時刻、長度與分類，刪除移除紀錄列；不新增欄位，既有欄位語意不變（ADR-0007）。長度仍是那一次的實際長度，只是改由使用者更正。完成順序鍵不變，統計依開始時刻歸日，CSV 依開始時刻排序。

## 與備份還原的關係

維持 ADR-0015 依識別碼合併、只新增不覆寫的規則：

- 還原較舊的備份不會蓋掉本機的更正；更正也不會透過備份傳到已有同一筆紀錄的另一台 Mac。
- 資料庫不記錄刪除，本機刪除而備份中仍有的紀錄會被帶回，與已刪除的分類相同，並計入還原預覽的「將新增」。

## Considered Options

- 還原時以備份內容覆寫同識別碼的紀錄：舊備份會蓋掉更正，需要修改時間與衝突規則才能判斷哪邊較新。
- 新增刪除與修改紀錄表：能在備份之間傳遞編輯，但要改資料結構，並定義不同裝置之間的先後；目前只有單機自用的需求。
- 編輯提供復原膠囊：要把編輯納入復原的整份換回，與計時操作的復原期限互相牽動；以刪除前的確認與可見的保存狀態代替。
- 允許編輯尚未保存的紀錄：重試時內容與已提交的版本不同會判為資料錯誤，要另外處理完成日誌與重試比對。
