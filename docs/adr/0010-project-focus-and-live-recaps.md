# 專注以分類歸屬，成果卡使用最新統計

使用者於 2026-10-29 確認：Project 是專注的分類，一次專注最多屬於一個分類，不引入 Goal、待辦或完成率。分類以穩定識別維持紀錄關聯；未指定分類的專注仍保留並計入統計，途中更正分類時整次專注歸到更正後的分類，不拆分時間。

成果卡是所選專注與所屬分類目前累積的呈現，不是完成當下的歷史快照。每次開啟或重新產生時重算分類總時間、次數、今日與最近七天統計；從舊紀錄開啟時，本次專注時間仍取自該筆紀錄，其他累積則使用最新資料。主格顯示分類累積專注時間，所有統計限同一分類；全部分類的彙總留在統計總覽。

## Considered Options

- 每次專注設定 Goal：使用者決定保留通用分類，避免擴張為任務與目標管理工具。
- 成果卡保存完成時快照：使用者明確選擇每次顯示最新累積，因此同一筆舊紀錄之後產生的成果卡可能不同；先前已匯出的圖片仍是靜態檔案。
- 以分類代表色取代計時階段色：代表色只用於分類標記、統計與成果卡，避免將歸屬與計時階段混為同一訊號。

## Consequences

既有完成的專注與計時語意依 ADR-0006 保留，資料新增與遷移遵守 ADR-0007。成果卡的本次長度與最新累積必須清楚標示，避免被理解為該筆專注完成當下的統計；完整實作與驗收規格見 [#18](https://github.com/latteine1217/ripen/issues/18)，規格發布不代表功能已實作。
