# 全 App 共用黑、白、玻璃三種外觀

2026-10-29 決定：外觀選擇為黑、白、玻璃。黑固定深色實色背景，白固定淺色實色背景；玻璃另外選擇跟隨系統、淺色或深色。這取代 spec #1 中主視窗與懸浮窗固定深色玻璃的限制，以及先做三種淺色原型再選擇的規劃。

- 主視窗、統計、懸浮窗、設定、標題列與 App 的系統對話框使用同一深淺色。外觀設定即時生效並存入既有 UserDefaults。
- 黑與白不透出桌面；玻璃沿用既有底色不透明度與背景模糊設定，切換實色時保留這些設定。玻璃的深淺色選擇亦獨立保留。
- 未選擇新外觀時保留原本深色玻璃；不改寫既有設定、完成的專注或資料結構。
- 淺色玻璃使用亮色磨砂材質、白底與細暗邊；深色保留原型玻璃。文字與控制項使用語意色，階段色與超時色各有淺色背景適用的較深配色。
- 瀏海島與水珠保留 ADR-0004 的純黑。水珠展開成淺色視窗時，視窗底色隨內容淡入。
- 全 App 以 AppKit 的 application appearance 統一系統介面；SwiftUI 的自訂背景依同一設定解析外觀，panel 不另外固定深色。

## Considered Options

- 深淺色與黑、白、玻璃完全獨立：黑底加淺色文字規則或白底加深色規則會產生不直觀的組合，因此讓黑、白直接決定模式。
- 只調整 SwiftUI 背景：會漏掉標題列、設定與系統對話框，也無法修復固定白字的懸浮窗。

## 驗收

設定須能跨啟動保留、非法值須回到相容預設；黑與白不受玻璃模式影響。測試保護既有深色階段色，並核對淺色階段色與超時色在白底上的對比。實機檢查主視窗、統計、設定、三尺寸懸浮窗、外觀即時切換及瀏海島的純黑例外；系統跟隨須檢查系統切換後的更新。

## 配色細化（2026-10-29）

黑與白以石墨黑／暖瓷白實作，背景與圓圈、數字等元件一起配色。黑與白均維持不透明，但改為微弱漸層，不使用純黑／純白平底。共用配色由 `AppPalette` 與 Asset Catalog 定義：

| 元件 | 石墨黑 | 暖瓷白 |
|---|---|---|
| 背景漸層 | #1C2025 → #242A30 | #F4F1EA → #EAE5DC |
| 主要文字與數字 | #E5E1D8 | #302E2A |
| 次要文字與暫停數字 | #9C9F9F | #6B655B |
| 圓環與進度軌道 | #343C43 | #DED8CD |
| 圓形按鈕 | #293139 | #E7E1D6 |

次要淺色文字比初提案略深，以維持漸層較暗一端的對比。階段色改為低飽和的珊瑚紅、綠、藍；超時保留青綠與橘的語意，深淺色分別調整明度。主按鈕的文字明確指定，暫停數字使用次要文字色，不再只降低透明度。過場底色沿用同一漸層，瀏海島與水珠仍依 ADR-0004 保留純黑。

本節取代前文「測試保護既有深色階段色」的數值要求；新的驗收保護色相區分與可讀性：主要文字對漸層兩端至少 7:1，次要文字、階段及超時文字至少 4.5:1，主按鈕文字對各階段底色至少 4.5:1。
